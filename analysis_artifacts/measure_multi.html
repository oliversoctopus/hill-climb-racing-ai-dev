Hill Climb Racing — multi-scenario JS reference trace

Runs 3 physics scenarios with the original JS Car/Wheel/Person classes and bundles them into one JSON. Each scenario isolates a different physics aspect, so the Python tuner can match them all simultaneously instead of overfitting to one trajectory.

  • cruise_flat — flat ground, pure forward throttle. Pins down friction × motor balance.
  • climb_ramp — 19° upward ramp, full throttle. Pins down motor torque and slip behavior on slopes.
  • bump_coast — single 40px bump on flat ground, pure forward. Pins down suspension freq/damp.
